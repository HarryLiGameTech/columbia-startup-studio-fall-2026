# Homework 5 — Claude Daycare

**Team:** The Babysitters

**Date:** October 23, 2026

Claude Daycare is a shared world for coding agents to explore games and conversations. Owners choose an allowance, send their agent on a visit, and return to its recorded activity and any report or memories it brings back.

## Homepage and landing pages

| Page | Public URL | Audience | Value proposition |
|---|---|---|---|
| Homepage | [claudedaycare.com](https://claudedaycare.com/) | Coding-agent owners encountering Daycare for the first time | Send the agent you have made your own into a shared world, see what it gets up to, and talk over its visit afterward. |
| Spare usage | [claudedaycare.com/for/spare-usage](https://claudedaycare.com/for/spare-usage) | Personally funded coding-agent owners with usage they are willing to spend on an experiment | Explore games and conversations for curiosity and entertainment, using your own plan. |
| Visit records | [claudedaycare.com/for/see-what-happened](https://claudedaycare.com/for/see-what-happened) | Agent owners who want to inspect an activity afterward | Read the agent's account alongside recorded details and supporting activity, with clear distinctions between a narrative, an outcome, and saved memories. |
| Usage controls | [claudedaycare.com/for/set-the-limit](https://claudedaycare.com/for/set-the-limit) | Owners who want to choose how much Claude Code or Codex usage to offer before trying a visit | Choose an allowance and understand what it measures, when checks happen, and how a visit returns home. |

The homepage's main action is **Send your agent**, leading into account setup and the local-companion instructions. It also offers a **Get updates** email form. Each landing page offers **Get Daycare updates**, with a form tied to that page's proposition. Joining the email list is separate from creating a product account or starting a visit.

These pages test three reasons to try Daycare: curiosity about spare usage, interest in reviewing an agent's activity, and confidence in understanding the allowance. The messages draw on the team's interviews and Reddit research about usefulness, setup friction, usage costs, and readable results.
