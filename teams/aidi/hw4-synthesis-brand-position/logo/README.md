# Aplovia logo assets

The selected mark combines the letters **A** and **V** with a route metaphor. The separated upper triangle reads as a destination, while the lower geometry suggests a guided path and forward movement. The narrower proportion makes the mark read clearly as an A. In every name lockup, the mark replaces the initial A and is followed by **plovia**; never show the mark followed by the full word **Aplovia**.

## Files

- `mark.svg`: primary Midnight Navy mark on a transparent background.
- `mark-white.svg` and `mark-black.svg`: one-color versions.
- `mark-square.svg`: square app-icon treatment.
- `lockup-light.svg` and `lockup-dark.svg`: horizontal mark-and-name lockups.
- `stacked-light.svg` and `stacked-dark.svg`: stacked compositions.
- `avatar.svg`: social-profile avatar.
- `favicon.svg`: scalable favicon source.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon-180.png`, `favicon-192.png`, and `favicon-512.png`: required raster favicon sizes.

Use the detailed spacing, color, minimum-size, and background rules in `../style_guide.md`.
