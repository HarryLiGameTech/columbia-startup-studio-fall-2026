# ZeroOne: HW5 MVP Doc, Homepage, and Landing Pages

CallIt gives a private group one shared record of its predictions and results. The main promise is: "Being right is better when your group remembers."

## Public pages

| Page | Audience and main value | URL |
|---|---|---|
| Homepage | Groups that want a shared prediction record | [call-it.app](https://call-it.app/) |
| Friends landing page | Friend groups that want to remember who called it | [Friends page](https://call-it.app/for/friends) |
| Sports landing page | Recurring sports groups that want to collect picks in one place | [Sports page](https://call-it.app/for/sports) |
| Agreements landing page | Groups that want to keep the original terms clear over time | [Agreements page](https://call-it.app/for/agreements) |
| Thank-you page | Shown after a saved email signup | [Thank-you page](https://call-it.app/thanks) |
